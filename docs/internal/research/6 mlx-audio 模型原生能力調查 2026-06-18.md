# mlx-audio STT 模型原生能力調查

調查日期：2026-06-18

本報告調查 std-mlx-audio 插件覆蓋的所有 STT 模型家族的**原生架構能力** —— 即模型本身和原始框架支持什麼，而非 mlx-audio 庫或 std-mlx-audio 適配器暴露了什麼。目的是識別標準協議設計（尤其是 diarization、timestamps、streaming、guidance 等特性）需要涵蓋的完整能力空間。

來源：arXiv 論文、HuggingFace 模型卡、官方 GitHub 倉庫、官方博客。

## 2. 詳述

### 2.1 Qwen3-ASR (Alibaba)

**論文:** arXiv:2601.21337 | **HF:** Qwen/Qwen3-ASR-0.6B, Qwen/Qwen3-ASR-1.7B | **Apache 2.0**

**架構:** AuT (Attention-based Universal Transcriber) 音頻 encoder，Conv2D stem (8x 時間下採樣)，12.5 Hz token rate，接 Qwen3 LLM decoder。

| 維度 | 能力 |
|---|---|
| **輸入** | 16 kHz mono，128-bin mel，最大 1200s (20 min)，靜音邊界自動分段 |
| **輸出** | 語言標籤 + 文字。格式: `language English<asr_text>transcribed text here` |
| **時間戳** | 模型本身不產生。需**分離模型** Qwen3-ForcedAligner-0.6B (NAR slot-filling, word/char/sentence 級, 42.9ms 平均偏移, 僅 11 語言) |
| **語言** | 52 (30 語言 + 22 中文方言)。LID 內建 (1.7B 97.9% 準確率)。支持 per-request 語言指定 |
| **Diarization** | 無 |
| **流式** | vLLM 限定。動態注意力窗口 (1–8s)，有狀態 session + prefix rollback。離線相比 ~24% WER 退化。流式無時間戳 |
| **引導** | context biasing via system prompt。軟偏置 —— "nudges probabilities, not forces" |
| **翻譯** | 無 |
| **其他** | 標點由 LLM decoder 原生產生。ITN/情感僅雲端 API (DashScope) |

### 2.2 Whisper (OpenAI)

**論文:** arXiv:2212.04356 | **HF:** openai/whisper-large-v3, openai/whisper-large-v3-turbo | **MIT**

**架構:** Audio Transformer encoder-decoder。encoder: 2 個 1D 卷積 (stride 2 下採樣至 1500 位置, ~20ms/位置) + 固定正弦位置編碼 + 自注意力。decoder: 自回歸 Transformer + 交叉注意力，學習位置編碼，最大 448 token/30s segment。

**模型尺寸:** tiny 39M → large-v3 1.55B (32/32 層, d=1280, 128 mel bins)。**Turbo 809M** = v3 decoder 從 32 層裁剪至 4 層 (~4-8x 加速, <1% WER 退化, 不支持翻譯)。

| 維度 | 能力 |
|---|---|
| **輸入** | 16 kHz mono via ffmpeg (~395 格式)。固定 30s chunk (短音頻零填充)。v1/v2: 80 mel bins; v3/turbo: 128 |
| **時間戳** | **segment 級**: 1501 個時間戳 token (20ms 精度)，成對出現。**word 級**: 交叉注意力權重 + DTW (非原始論文, 代碼庫添加, `whisper/timing.py`) |
| **語言** | 99 (v1/v2), 100 (v3, 加粵語)。偵測: SOT 後第一步 softmax over 語言 token。~80% Fleurs 準確率 |
| **Diarization** | 無 |
| **流式** | 無原生流式。固定 30s chunk 處理 |
| **引導** | `initial_prompt`: tokenized, 以 `<\|startofprev\|>` 前綴 (最大 223 token)。`condition_on_previous_text`: 前段輸出作為下段 prompt。`suppress_tokens`: logit 遮罩 |
| **翻譯** | X→EN (99 語言, 125K 小時訓練)。**Turbo 不支持翻譯** |
| **其他** | 溫度 fallback (0.0→1.0), beam search, no_speech 概率 (閾值 0.6), 幻覺偵測 |

### 2.3 Parakeet TDT (NVIDIA)

**論文:** arXiv:2305.05084 (FastConformer), arXiv:2304.06795 (TDT, ICML 2023) | **HF:** nvidia/parakeet-tdt-0.6b-v3 | **CC-BY-4.0**

**架構:** FastConformer encoder (16 blocks, 384 dim, 4 heads, 8x 下採樣, depthwise separable convolutions) + Token-and-Duration Transducer decoder。TDT 的 joint network 同時輸出兩個獨立 softmax: token 分布 P_T 和 duration 分布 P_D。blank 和 non-blank 都可跳多幀 → 比 RNNT 少 ~2-5x joint network 調用 → 2.27-2.82x 推理加速。

| 維度 | 能力 |
|---|---|
| **輸入** | 16 kHz mono。Full attention A100: ~24 min; local attention: ~3 小時 |
| **時間戳** | **word/segment/char 級**。TDT 原生預測每 token 的 duration (幀覆蓋)。word/char/segment 分組通過 NeMo `compute_timestamps` 後處理 |
| **語言** | v2: 英語。v3: 25 歐洲語言 + 自動偵測 + code-switching |
| **Diarization** | 無 (需分離 pipeline: NeMo MSDD/Sortformer/pyannote) |
| **流式** | 非原生。偽流式 via NeMo chunked/buffered 推理腳本 |
| **引導** | 無原生 prompting。GPU 加速 Phrase Boosting (shallow-fusion beam search) 開發中, ~100 詞限制 |
| **其他** | 標點和大小寫原生 (BPE 詞表)。ITN 非原生 (分離 WFST)。RTFx 3,332 |

### 2.4 Nemotron ASR (NVIDIA)

**論文:** arXiv:2305.05084, arXiv:2312.17279 (Cache-aware streaming) | **HF:** nvidia/nemotron-3.5-asr-streaming-0.6b | **NVIDIA OML / OpenMDW-1.1**

**架構:** 與 Parakeet 相同 FastConformer encoder，但配 **RNNT decoder** (非 TDT)。RNNT: blank 前進 1 幀, non-blank 保持位置。原生流式；TDT 離線更快。Nemotron-3.5 使用 128 mel bins, 13,087 詞表, 128-dim 語言向量。

| 維度 | 能力 |
|---|---|
| **輸入** | 16 kHz mono |
| **時間戳** | RNNT 解碼對齊路徑副產品。~80ms 精度 (8x 下採樣)。word/segment/char via NeMo 後處理。**流式模式目前壞掉** (GitHub #14714) |
| **語言** | EN 版: 英語。3.5 版: 40 locales (19 轉寫就緒 + 13 廣覆蓋 + 8 適應就緒), 含 CJK |
| **流式** | **原生 cache-aware 流式** — 核心差異。每音頻幀僅處理一次。三種緩存: 自注意力 KV (FIFO), 卷積 (K-1 活化), RNNT decoder 隱藏狀態。多延遲訓練: 單模型支持 80ms/160ms/320ms/560ms/1120ms。BSF 1.03 (僅 3% WER 退化)。H100 上可達 2,400 並發流 |
| **Diarization** | 無。分離 pipeline (MarbleNet VAD + TitaNet 嵌入 + 聚類 + MSDD) |
| **其他** | 端句偵測 (`parakeet_realtime_eou_120m-v1`, p50: 160ms)。統一 offline+streaming 模型存在 |

### 2.5 SenseVoice (Alibaba/FunASR)

**論文:** arXiv:2407.04051 | **HF:** FunAudioLLM/SenseVoiceSmall | **Model Agreement**

**架構:** 非自回歸, 僅 encoder, CTC。234M 參數。SAN-M (Self-Attention with Memory) 層: 多頭自注意力 + FSMN (depthwise Conv1d)。50 encoder blocks。**4-Token 前綴系統 (核心創新)**: 4 個學習嵌入 token 前綴於語音特徵，CTC 投影同時用於多任務:

| 位置 | 預測 | 值 |
|---|---|---|
| 0 | 語言 ID | `<\|zh\|>`, `<\|en\|>`, `<\|yue\|>`, `<\|ja\|>`, `<\|ko\|>`, `<\|nospeech\|>` |
| 1 | 音頻事件 | `<\|BGM\|>`, `<\|Speech\|>`, `<\|Applause\|>`, `<\|Laughter\|>`, `<\|Cry\|>`, `<\|Sneeze\|>`, `<\|Breath\|>`, `<\|Cough\|>` |
| 2 | 情感 | `<\|HAPPY\|>`, `<\|SAD\|>`, `<\|ANGRY\|>`, `<\|NEUTRAL\|>`, `<\|FEARFUL\|>`, `<\|DISGUSTED\|>`, `<\|SURPRISED\|>` |
| 3 | ITN 模式 | `<\|withitn\|>`, `<\|woitn\|>` |

| 維度 | 能力 |
|---|---|
| **輸入** | 16 kHz mono, 80-bin mel, LFR 7x 堆疊 + 6x 下採樣 (~60ms)。**最大 30 秒** |
| **時間戳** | 非原始架構。2024-11 通過 CTC forced alignment 添加。~60ms 精度 |
| **語言** | 5 (zh, en, yue, ja, ko)。SenseVoice-Large 支持 50+, 但 Small 限 5 |
| **Diarization** | 無 (外部 pipeline: FSMN-VAD + CAM++ 可用) |
| **流式** | 無。論文明確: "SenseVoice is not designed for streaming" |
| **其他** | **情感偵測** (7 類, per-utterance)。**音頻事件偵測** (8+ 類, per-utterance)。**ITN + 標點** 內建。速度: 10s 音頻 70ms (RTF 0.007), 5x Whisper-Small |

### 2.6 Cohere Transcribe

**HF:** CohereLabs/cohere-transcribe-03-2026 | **Apache 2.0** | **無 arXiv 論文**

**架構:** 2B 參數。FastConformer encoder (48 層, 1280 dim, 8 heads) + 輕量 Transformer decoder (8 層, 1024 dim)。從零訓練, 非 Whisper 衍生。500K 小時訓練數據。

| 維度 | 能力 |
|---|---|
| **輸入** | 16 kHz mono, 128 mel bins。最大 35s/chunk, 自動分段含 5s overlap, 支持 55+ 分鐘 |
| **時間戳** | **不支持**。模型卡明確聲明。詞表無時間戳 token, 無 CTC path |
| **語言** | 14 (en, fr, de, it, es, pt, el, nl, pl, zh, ja, ko, vi, ar)。**必須手動指定**, 無自動偵測 |
| **Diarization** | 無 |
| **流式** | 無 |
| **引導** | 最小 (語言標籤 + 標點開關) |
| **其他** | Open ASR Leaderboard 發布時 #1, avg WER 5.42%。RTFx 524.88。幻覺傾向 (推薦 VAD) |

### 2.7 Voxtral (Mistral)

**論文:** arXiv:2507.13264 | **HF:** mistralai/Voxtral-Mini-3B-2507, mistralai/Voxtral-Mini-4B-Realtime-2602 | **Apache 2.0**

**兩個根本不同的模型:**

| 方面 | Voxtral Mini 3B (2025-07) | Voxtral Realtime 4B (2026-02) |
|---|---|---|
| **架構** | Whisper-large-v3 encoder (雙向, ~640M) + MLP (4x 下採樣) + Ministral 3B decoder | 自定義因果 encoder (從零訓練, ~970M, 滑動窗口 750 token) + MLP + Ministral-3 decoder (滑動窗口 8192)。Ada RMSNorm 時間條件 |
| **用途** | 離線音頻語言模型 (轉錄 + QA + 翻譯 + **function calling**) | **純流式即時 ASR** |
| **語言** | 8 (en, es, fr, pt, hi, de, nl, it) | 13 (加 zh, ar, ru, ja, ko) |
| **流式** | 否 (雙向 encoder) | **原生因果**。可配延遲 80ms–2400ms。通過滑動窗口支持無限長度 |
| **翻譯** | Yes (SOTA BLEU) | No |
| **其他** | 音頻 QA, 摘要, **語音 function calling**, 多輪對話 | 純轉錄。M3 Max ~2.5x 即時 |

**API 限定功能 (開源權重無):** word 級時間戳, speaker diarization, context biasing/custom vocabulary (均 Transcribe V2 API 限定)。

### 2.8 Canary (NVIDIA NeMo)

**論文:** arXiv:2509.14128 (v2), arXiv:2503.05931 (flash) | **HF:** nvidia/canary-1b-v2 | **CC-BY-4.0**

**架構:** FastConformer encoder + Transformer decoder (交叉注意力)。非 LLM (傳統 encoder-decoder, `EncDecMultiTaskModel`)。例外: canary-qwen-2.5b 使用 FastConformer + Qwen3-1.7B (SALM)。

多任務 token prompting (Canary2 格式):
```
<|startofcontext|> [context] <|startoftranscript|> <|emotion|> <|source_lang|> <|target_lang|> <|pnc|> <|itn|> <|timestamp|> <|diarize|> ... text ... <|endoftext|>
```

| 維度 | canary-1b | canary-1b-flash | canary-1b-v2 |
|---|---|---|---|
| **語言** | 4 | 4 | 25 歐洲 |
| **時間戳** | No | Yes (實驗性, word+segment, 厘秒 special tokens) | Yes (CTC aligner + NeMo FA) |
| **翻譯** | 6 pairs (en↔de/es/fr) | 同上 | **48 pairs** (en↔24 langs) |
| **PnC** | `<\|pnc\|>` toggle | 同上 | 同上 |
| **ITN** | No | `<\|itn\|>` toggle | Yes |
| **Diarization** | No | No | **No** (prompt slot `<\|diarize\|>` 存在但無模型訓練過) |
| **流式** | No | No | 有限 (chunked, 已知 20-40s 後停止問題) |

### 2.9 Qwen2-Audio (Alibaba)

**論文:** arXiv:2407.10759 | **HF:** Qwen/Qwen2-Audio-7B-Instruct | **Apache 2.0**

**架構:** Whisper-large-v3 encoder (~637M) + AvgPool1d(2) + Linear connector + Qwen-7B decoder。~8.2B 參數。**通用音頻語言模型**, 非專用 ASR。

| 維度 | 能力 |
|---|---|
| **輸入** | 16 kHz mono, **最大 30 秒** (硬限制) |
| **時間戳** | 無 (v1 Qwen-Audio 有 SRWT word 級, v2 完全刪除) |
| **語言** | ~8 (zh, en, yue, fr, it, es, de, ja)。遠少於 Whisper 99 |
| **Diarization** | 無 (可識別說話人特徵如 "a man speaking", 但無結構化標籤) |
| **翻譯** | Yes (CoVoST2 SOTA, 7 方向) |
| **其他能力** | 音頻標題生成, 音頻事件偵測, 人聲分類 (咳嗽/噴嚏/笑聲 93.9%), 語音情感識別 (55.3% MELD), 音樂理解 (曲風/樂器/調性/節奏/標題), 聲景分類, 說話人年齡/性別估計 |
| **ASR vs Whisper** | 8 語言 WER 有競爭力, 但缺乏所有生產 ASR 功能 |

### 2.10 VibeVoice ASR (Microsoft)

**論文:** arXiv:2601.18184 | **HF:** microsoft/VibeVoice-ASR-HF | **MIT**

**架構:** ~9B 參數 SALM (Speech-Augmented Language Model)。雙音頻 tokenizer (聲學 sigma-VAE + 語義確定性 encoder, 各 ~340M, 3200x 下採樣至 7.5 Hz) → Qwen2.5-7B LLM decoder。1 小時音頻壓縮至 ~27K latent token (在 64K 上下文窗口內)。

| 維度 | 能力 |
|---|---|
| **輸入** | 24 kHz mono, **最大 60 分鐘**。接受 wav/mp3/flac/m4a/ogg/opus + URL/numpy |
| **輸出** | 結構化 JSON 陣列: `{"Start": float, "End": float, "Speaker": int, "Content": str}` |
| **時間戳** | segment 級 (非 word 級)。浮點秒, 厘秒精度。LLM 作為文字 token 生成 (字面數字, 非 special token) |
| **語言** | 50+ (51 標籤)。66.65% 英語, 14.39% 中文, 6.28% 西班牙語。原生 code-switching |
| **Diarization** | **Yes — 原生 joint 模型**。LLM 在單一自回歸 pass 中交織生成 "Who" (Speaker: N), "When" (Start/End), "What" (Content)。無 special speaker token — speaker ID 是普通整數文字 token。無硬編碼最大說話人數。60 分鐘內標籤一致 |
| **引導** | hotword/context 注入 (prompt tokenized + 前綴於音頻 latent 序列, 偏置生成而非後處理替換) |
| **Diarization 基準** | MLC-Challenge (12 語言): Mean DER 3.42%, tcpWER 15.66% — vs Gemini-2.5-Pro DER 16.29% |
| **其他** | 非語音事件標籤: `[Silence]`, `[Music]`, `[Human Sounds]`, `[Environmental Sounds]`, `[Noise]`, `[Unintelligible Speech]`。重疊語音序列化至主說話人 (已知限制) |

### 2.11 GLM-ASR Nano (Zhipu AI / Z.AI)

**HF:** zai-org/GLM-ASR-Nano-2512 | **無 arXiv 論文** | **許可證未公開**

**架構:** Whisper-large-v3 encoder (微調, 32 層, d=1280) + GELU projector (1280→2048, 2x merge) + 自定義小型 Llama decoder (28 層, d=2048, 16Q/4KV GQA, vocab 59264, max 8192 位置)。~1.5B。**非 GLM-4-Voice** (不同組織, 不同模型家族)。

| 維度 | 能力 |
|---|---|
| **輸入** | 16 kHz mono, **最大 655 秒** (~10.9 min, 受 8192 token 上下文窗口限制) |
| **輸出** | 純文字 |
| **時間戳** | 無 |
| **語言** | 17 (WER≤20%): 普通話, 英語, 粵語, 四川話, 閩南語, 吳語, 法/德/日/韓/西/阿等 |
| **流式** | 開源無。雲端 API 支持 SSE |
| **引導** | chat-template prompting。雲端 API 添加 `prompt` (context) + `hotwords` (最多 100 項) |
| **其他** | 低音量語音優化 — "specifically trained for whisper/quiet speech scenarios" |

### 2.12 Granite Speech (IBM)

**論文:** arXiv:2604.11269 (diarization), arXiv:2505.08699 (原始 3.3), arXiv:2603.08397 (NAR) | **Apache 2.0**

**架構:** Conformer encoder (16 層, block-attention 4s 窗口, self-conditioned CTC) + Q-Former projector (2 層窗口 query transformer, 5x 下採樣→10 Hz) + Granite LLM + LoRA (rank 64)。encoder 和基礎 LLM 權重凍結。

**完整變體功能矩陣:**

| 功能 | 3.3-2b | 3.3-8b | 4.1-2b | **4.1-plus** | 4.1-nar |
|---|---|---|---|---|---|
| ASR | 5 lang | 5 lang | 6 lang (+Ja) | 5 lang | 5 lang |
| 翻譯 | X↔En + En→Ja,Zh | 同上 | X↔En (6 lang) | **無** | **無** |
| 標點/大小寫 | No | No | **Yes** | No | No |
| Keyword biasing | No | No | Yes | **Yes** | No |
| **Diarization** | No | No | No | **Yes** | No |
| **Word timestamps** | No | No | No | **Yes** | No |
| RTFx (H100) | 271 | 145 | 231 | ~231 | **~1820** |

**4.1-plus diarization 細節:** 通過 prompt 觸發 ("Speaker attribution: Transcribe and denote who is speaking by adding [Speaker 1]: tags")。自動偵測說話人數。訓練創新: Speaker Cluster Identification (WavLM-ECAPA 嵌入 k-means 100 clusters)。WDER: Fisher 0.9%, CallHome 2.2% (vs PyAnnote+Whisper 11.7%/17.1%)。限制: >6-7 人退化, 最大 9 min。

**4.1-plus timestamps:** word 級 via `[T:N]` token (厘秒 mod 1000)。LS-Clean 11.4ms, LS-Other 14.6ms 平均偏移。最大 3.5 min。

**4.1-nar:** 非自回歸 LLM 編輯。CTC draft + 雙向 LLM 單 forward pass 預測 4 種編輯 (copy/insert/delete/replace)。RTFx ~1820 (AR 的 ~8x)。

### 2.13 Moonshine (Useful Sensors)

**論文:** arXiv:2410.15608 (v1), arXiv:2602.12241 (v2) | **MIT**

**架構:** v1: encoder-decoder seq2seq Transformer。**無 mel 頻譜圖** — 原始 16kHz 波形通過 3 層卷積 stem (strides 64/3/2 = 384x 壓縮)。RoPE。知識蒸餾自 Whisper。v2: **Ergodic encoder** 滑動窗口自注意力，無位置編碼 (時間平移不變)，SwiGLU FFN，狀態 tensor。

| 維度 | v1 | v2 |
|---|---|---|
| **參數** | Tiny 27M, Base 62M | Tiny 34M, Small 123M, Medium 245M |
| **流式** | 無 (全注意力) | **原生** (ergodic 滑動窗口, 最大右上下文 80ms) |
| **時間戳** | 無 | 無 (CTC 列為未來工作) |
| **語言** | 英語 | 英語 (多語言微調是分離 checkpoint) |
| **引導** | 無 | 無 |
| **關鍵差異** | 極致邊緣效率。v2 Medium (245M) 比 Whisper Large v3 (1.55B) 快 43.7x, WER 更低 (6.65% vs 7.44%)。RPi5: Tiny 237ms, Medium 802ms (Whisper Tiny: 5,863ms) |

### 2.14 MMS (Meta)

**論文:** arXiv:2305.13516 | **HF:** facebook/mms-1b-all | **CC-BY-NC 4.0**

**架構:** wav2vec 2.0 (~965M)。CNN 特徵 encoder (7 層, stride 320 = 20ms/幀) + 48 層 Transformer encoder (d=1280, 16 heads)。CTC head + **per-language adapter** (每語言 ~2M 參數, LayerNorm → down 1280→16 → ReLU → up 16→1280, 插入每個 Transformer block)。

| 維度 | 能力 |
|---|---|
| **語言** | **1,162** 語言 ASR (mms-1b-all)。語言必須顯式指定 (`model.load_adapter("fra")`)。自動偵測用分離 LID 模型 (最多 4,017 語言) |
| **時間戳** | **char 級原生 via CTC 幀對齊** (20ms 精度)。word 級通過字符分組。也有專用 MMS_FA 強制對齊模型 (1,130 語言) |
| **輸出** | CTC 字符級。原生腳本字符 (<200 字符的語言) 或 uroman 拉丁化 (≥200 字符, 如中日文) |
| **流式** | 無 (雙向 Transformer) |
| **引導** | 無 (CTC 無 decoder 可 prompt)。可選 KenLM (20-gram, 102 語言) shallow-fusion |
| **其他** | 相關 MMS 模型: TTS (1,107 語言), LID (4,017 語言), FA (1,130 語言)。vs Whisper: 54 FLEURS 語言 58% 相對 WER 降低, 覆蓋 11x 更多語言 |

### 2.15 FireRedASR2 (小紅書/RedNote)

**論文:** arXiv:2501.14350 (v1), arXiv:2603.10420 (v2/2S) | **Apache 2.0** | **注意: 小紅書 (RedNote), 非小米**

**架構:** AED (Attention-based Encoder-Decoder) = Conformer encoder + Transformer decoder (交叉注意力, 非 CTC/transducer)。LLM 變體 = Conformer encoder + adapter + Qwen2-7B-Instruct (LoRA)。

| 維度 | AED | LLM |
|---|---|---|
| **參數** | 140M–1.1B | 7.7B–8.3B |
| **時間戳** | **v2 AED: word 級** (CTC 分支 forced alignment) | 無 |
| **語言** | 普通話 + 英語 + 20+ 中文方言 + code-switching | 同上 |
| **流式** | 無 | 無 |
| **引導** | 無 | 內部 (非用戶面向) |
| **其他** | v2 AED 完整輸出: text, sentences[] (start/end/confidence/lang), words[], vad_segments, dur。歌詞識別 (CER 1.12%)。SOTA 普通話: LLM 2.89% CER |

### 2.16 Paraformer (Alibaba/FunASR)

**論文:** arXiv:2206.08317 (Interspeech 2022), arXiv:2308.03266 (SeACo, ICASSP 2024) | **Model-specific license**

**架構:** **非自回歸 (NAR)** — 單 forward pass 生成所有 token (10x+ AR 加速)。220M。SAN-M encoder (50 層) + CIF predictor (連續整合發射, 軟單調對齊) + GLM sampler (訓練限定) + 16 層雙向 SAN-M decoder。

| 維度 | 能力 |
|---|---|
| **時間戳** | **CIF 原生** — 每個 CIF 發射位置映射到時間點。~71ms AAS。(注意: Paraformer-v2 用 CTC 替換 CIF, 刪除 CIF 時間戳) |
| **語言** | paraformer-zh: 中文+英語 (code-switching)。paraformer-en: 英語。非大規模多語言 |
| **流式** | Yes (chunked 變體, `paraformer-zh-streaming`, 220M)。config `chunk_size = [lookback, chunk, lookahead]`, ~900ms 延遲 |
| **引導** | **SeACo-Paraformer**: hotwords via bias encoder (2 層 LSTM) + bias decoder (4 層 Transformer)。基礎 Paraformer 完全凍結。`hotword='keyword weight'`。~60-65% 困難 hotword recall |
| **其他** | 標點: 非內建 (分離 CT-Transformer)。ITN: 非內建 (FST)。FunASR pipeline 組合: FSMN-VAD → Paraformer → CT-Punc → FST-ITN |

**Fun-ASR Nano 澄清:** "Fun-ASR-Nano" 不是 Paraformer 變體, 是完全不同的 LLM 架構 (audio encoder + Qwen3-0.6B, 800M, CTC 初始假說 + LLM 精煉, 31 語言)。

## 3. 對標準協議設計的啟示

### 3.1 Diarization

僅 2/16 mlx-audio 模型家族有原生 diarization:
- **VibeVoice ASR**: joint 模型, 在轉錄同時生成 speaker ID (最有建築學意義)
- **Granite Speech 4.1-plus**: prompt 觸發, encoder 第 3 層拼接保留說話人判別信息

Canary v2 有 `<|diarize|>` prompt slot 但尚無訓練模型 — 預留了未來支持。其餘 14 個模型完全不支持。

**對 std-mlx-audio 的影響:** VibeVoice 的 `GenericSttBackend` 已解析 JSON segments 但未映射 `Speaker` → `Segment.speaker`。這是 diarization 在 mlx-audio 插件落地的最自然切入點。

### 3.2 時間戳

架構多樣性極大:
- **TDT native duration** (Parakeet): 每 token 預測幀數
- **RNNT alignment path** (Nemotron): 解碼副產品
- **CIF fire location** (Paraformer): 連續整合發射
- **CTC frame alignment** (MMS, SenseVoice): 幀級概率
- **Whisper token + DTW** (Whisper): segment token + 交叉注意力 DTW word 級
- **LLM 文字 token** (VibeVoice, Granite): 模型作為文字生成時間值
- **Special tokens** (Canary): `<|timestamp|>` 厘秒 token

標準的 `word_timestamps` granularity 系統 (`word | segment | char`) 已正確涵蓋所有情況。

### 3.3 流式

三種根本不同的流式策略:
- **原生 cache-aware** (Nemotron): 每幀處理一次, 多延遲訓練
- **原生因果** (Voxtral Realtime, Moonshine v2): 因果 encoder, 滑動窗口
- **偽流式/chunked** (Parakeet, Qwen3-ASR, Paraformer, Canary): 窗口化重解碼

標準的流式協議 (partial/final/supersede) 已正確抽象了底層差異。

### 3.4 超出當前標準範圍的能力

以下能力存在於模型中但標準尚未覆蓋:
- **情感偵測** (SenseVoice: 7 類; Qwen2-Audio)
- **音頻事件偵測** (SenseVoice: 8+ 類; Qwen2-Audio; VibeVoice 非語音標籤)
- **語音 function calling** (Voxtral Mini)
- **非自回歸 LLM 編輯** (Granite NAR)
- **歌詞識別** (FireRedASR2)
- **音樂理解** (Qwen2-Audio)
- **端句偵測** (Nemotron EOU)

這些應作為未來 additive 特性的參考, 不阻塞 diarization 設計。
